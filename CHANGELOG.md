## [0.1.0] - 2026-11-18

### Added
- Приложение ChipClean на Rust (egui/eframe, Windows 10/11 x64).
- Очистка системы: временные файлы, кэши, логи, отчёты об ошибках, обновления
  Windows, корзина, загрузки.
- Реестр: безопасная проверка, редактор с поиском и заменой, импорт `.reg`
  с предпросмотром, снимки, откат.
- Автозагрузка: Run/RunOnce, папки, задачи планировщика, службы — отключение
  с карантином.
- Личные данные: история браузеров, недавние документы, списки файлов.
- Чистка сообществом: правила winapp2.ini (FileKey/RegKey HKCU/HKLM, Detect,
  Default, Warning, ExcludeKey).
- Твики: 51 скрытая настройка Windows по образцу Reg Organizer, с `.reg`-бэкапами.
- Фоновая очистка: ежедневная задача и проверка при входе через COM Task Scheduler.
- Экспресс-проверка: запуск всех сканов одной кнопкой.
- Анализ диска: крупнейшие файлы и занятость томов.
- Точка восстановления Windows (кнопка в Центре отката).
- Мастер деинсталляции со снимком реестра и очисткой следов.
- Контекстное меню `.reg` в Проводнике.
- Локализация интерфейса: русский / английский.
- Современное HTML5-руководство (вместо CHM).
- Журнал операций, резервные копии, карантин.

### Changed
- Первичный вызов реестра и планировщика переведён на windows-registry и COM
  (без внешних `reg.exe`/`schtasks.exe`).
- Значения твиков типизированы (Dword/Text/Absent).

### Security
- Правила из интернета скачиваются только по явной команде и не выполняются.
- Перед изменением значений твиков создаётся `.reg`-копия.
