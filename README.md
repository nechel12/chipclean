# ChipClean

Быстрая утилита для очистки и обслуживания Windows на Rust. Нативный интерфейс,
тёмная красно-чёрная тема, прозрачный скан и безопасные правила по умолчанию.

> Статус: рабочий каркас. Реализован интерфейс и read-only сканер.
> Удаление файлов, очистка реестра, автозагрузка и деинсталлятор — следующие этапы.

## Что уже работает

- Нативное окно `eframe/egui` без WebView, с системным Segoe UI и Phosphor-иконками.
- 18 категорий очистки в трёх группах: система, браузеры/GPU, личные данные.
- Реальное сканирование: размер, количество файлов, ошибки доступа, отмена.
- Сканирование в фоновом потоке, интерфейс не блокируется.
- Запрос прав администратора через UAC при запуске release-сборки.
- Отдельные предупреждения для «Загрузок» и корзины (подтверждение — на этапе удаления).
- Настройки в `%APPDATA%\ChipClean\ChipClean\config\settings.json`, журналы в
  `%LOCALAPPDATA%\ChipClean\ChipClean\data`.
- Защита от обхода reparse point/junction при рекурсивном сканировании.
- «Загрузки» сканируются только на верхнем уровне и только старше заданного срока.

## Стек

| Слой | Решение |
|------|---------|
| Язык | Rust 2024, MSVC, Windows 10/11 x64 |
| GUI | `eframe` / `egui` 0.36, `egui-phosphor` 0.14 |
| Win32 | `windows` 0.62: Shell, COM, файловая система, UAC |
| Сканирование | `walkdir`, `crossbeam-channel`, `glob`, фоновый поток |
| Данные | `serde`, `serde_json`, `directories` |
| Логи | `tracing`, `tracing-appender`, `tracing-subscriber` |
| Ошибки | `anyhow` |
| Один экземпляр | `single-instance` |

Планируется добавить `windows-registry` для реестра и `rayon`/`sysinfo` только
если профилирование покажет пользу.

## Структура

```text
src/
  main.rs              точка входа, логирование, UAC, единственный экземпляр
  app.rs               состояние приложения, навигация, тосты
  theme.rs             палитра, типографика, системные шрифты, стили egui
  config.rs            настройки и каталоги данных
  ui/
    sidebar.rs         логотип, навигация, статус администратора, диск
    cleanup.rs         экран очистки, группы категорий, прогресс
    registry.rs        план безопасной очистки реестра
    startup.rs         план менеджера автозагрузки
    uninstall.rs       план удаления программ
    settings.rs        правила «Загрузок», гарантии, пути, о программе
    widgets.rs         навигация, чекбоксы, кнопки, переключатели, прогресс
    common.rs          заголовки и пустые состояния
    format.rs          размеры и склонение «файл/файла/файлов»
  core/
    model.rs           модели категорий и источников путей
    catalog.rs         каталог 18 разделов чистки
    scanner.rs         фоновый read-only скан
    state.rs           состояние скана, результаты, отмена
  win/
    elevation.rs       проверка прав и перезапуск через UAC
    paths.rs           известные папки (Downloads)
    disk.rs            свободное место на системном диске
    recycle_bin.rs     размер корзины
    dialog.rs          системные сообщения об ошибках
```

## Безопасность

- Сейчас приложение **ничего не удаляет** — только читает метаданные.
- Рискованные и расширенные разделы не выбраны по умолчанию.
- «Загрузки» и корзина помечены как требующие отдельного подтверждения.
- При сканировании не используются символические ссылки и reparse points,
  кроме корня выбранной категории.
- В release-сборке приложение требует права администратора.
- Перед будущей правкой реестра будет создаваться `.reg`-бэкап, а удаление —
  только после явного подтверждения.

## Сборка и запуск

Требуются Rust stable и Visual Studio Build Tools (MSVC).

```powershell
cargo build --release
.\target\release\chipclean.exe
```

Для разработки можно отключить UAC-перезапуск (только debug-сборка):

```powershell
$env:CHIPCLEAN_SKIP_ELEVATION = "1"
cargo run
```

Проверки:

```powershell
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
```
