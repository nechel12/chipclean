# ChipClean

Бесплатная утилита для очистки и обслуживания Windows, написанная на Rust.

> Статус: проектирование, каркас проекта.

## Цель

Быстрая, предсказуемая и безопасная альтернатива классическим «чистильщикам»
реестра и диска: мгновенный отклик интерфейса, прозрачный список найденного,
обязательный бэкап перед изменениями и никаких «тихих» удалений.

## Планируемый функционал

- Очистка диска: временные файлы, кэши, логи, отчёты об ошибках, эскизы,
  кэши браузеров, кэши NVIDIA/DirectX, старые обновления.
- Отдельное подтверждение перед очисткой папки «Загрузки» и корзины.
- Безопасная очистка реестра: неверные пути, битые записи автозагрузки,
  осиротевшие записи деинсталлятора — с экспортом `.reg` перед правкой.
- Менеджер автозагрузки: просмотр, включение и отключение записей.
- Удаление программ: список установленного, запуск штатных деинсталляторов.
- Настройки, журнал операций и восстановление из бэкапа.

## Стек (предварительно)

| Слой | Решение |
|------|---------|
| Язык | Rust 2024 edition, MSVC toolchain |
| GUI | `eframe` / `egui` + `egui-phosphor` (нативный рендер, один exe, без WebView) |
| Windows API | `windows` (Shell, COM, файловая система), `windows-registry` |
| Сканирование | `walkdir`, `rayon`, `crossbeam-channel`, фоновые потоки + отмена |
| Данные | `serde`, `serde_json`, `directories` |
| Логи | `tracing`, `tracing-subscriber` |
| Ошибки | `anyhow`, `thiserror` |
| Утилиты | `sysinfo`, `humansize`, `chrono` |
| Сборка | Cargo, GitHub Actions, портативный zip (+ установщик позже) |

## Структура

```text
src/
  main.rs          точка входа, манифест, единственный экземпляр
  app.rs           состояние приложения и навигация
  theme.rs         красно-чёрная тема, типографика, отступы
  ui/              экраны: очистка, реестр, автозагрузка, программы, настройки
  core/            сканеры, категории очистки, планировщик задач, прогресс
  win/             обёртки над Win32: пути, корзина, реестр, COM, elevation
  config.rs        настройки и журнал операций
```

## Безопасность

- Сначала скан и предпросмотр, удаление — только по явному действию.
- Рискованные категории выключены по умолчанию.
- «Загрузки» и корзина требуют дополнительного подтверждения.
- Перед правкой реестра создаётся резервная копия затронутых ключей.
- Все операции пишутся в журнал.

## Сборка

```powershell
cargo build --release
```

Требуется Rust stable и Visual Studio Build Tools (MSVC).
